# 墨页

简约的本地 Markdown 阅读器，使用 Go、Wails v3、Vue 3 和 TypeScript，当前交付 Windows x64 桌面版。

## 下载

从 [Releases](https://github.com/fengfengzhidao/markdown-preview/releases/latest) 下载 Windows x64 版本。ZIP 解压后运行 `MarkdownLite.exe`，也可以直接下载 EXE。系统需要 WebView2 Runtime，发布附件中的 `SHA256SUMS.txt` 提供文件校验值。

## 使用

运行 `bin/MarkdownLite.exe`。通过文件列表顶部“打开”选择一个或多个 `.md` / `.markdown` 文件，也可将文件拖入窗口，或把文件路径作为启动参数传入。

墨页使用单实例运行。再次通过 EXE 打开文件时，会在已有窗口中打开对应标签并唤起窗口。重复打开同一个文件会切换到已有标签，编辑中的内容继续保留。启动过程中或保存、重命名提示显示期间收到的文件，会排队等待界面准备完成。

窗口标题栏搭配书页图标，紧凑顶栏放置文件标签和原文 / 分栏 / 预览切换。拖动文件标签可以调整顺序，拖到标签栏边缘会自动滚动，按 Esc 可取消拖动。点击鼠标中键可以关闭标签，有未保存修改时会提示处理。右侧“…”菜单提供复制 Markdown、编辑锁定和黑夜模式切换，主题选择会在下次启动时恢复。

未打开文件时显示欢迎页，提供功能说明、使用指引、快捷键，以及打开文件和新建文档的入口。

分栏宽度支持拖动调整。文件单独保留阅读位置、显示模式和编辑撤销历史。

左侧文件列表顶部提供“新建”和“打开”操作，列表按最近打开顺序记录本地文件，点击条目可切换或重新打开文章。列表在重启后恢复，新文档首次保存、文件重命名时也会更新记录。可通过顶栏按钮折叠列表，通过条目右侧的“×”移除记录。文件路径记录保存在 `%APPDATA%\Moye\recent-files.json`。

标签总宽度超出顶栏可用空间时，显示“更多文章”按钮。点击可从菜单中切换到任意已打开的文章，菜单同时显示文件名、路径、当前文章和未保存状态，支持上下方向键选择及 Enter 切换。

右键文件标签或“更多文章”中的条目，可打开当前文件夹、复制文件路径或重命名。重命名会同步修改磁盘文件与标签信息。未保存文档可以先改名，首次保存时使用所选名称。

右键顶部标签栏的空白区域，可选择“清空所有”“新建文档”“打开文档”。“清空所有”会关闭全部标签，未保存的修改会逐篇提示保存，选择取消后可继续编辑。

编辑锁定默认开启。关闭锁定即可修改原文，预览会随输入更新。修改后的标签显示小圆点，“保存”按钮按需出现。切回锁定后可继续保存已有改动，关闭标签或退出时会提示处理尚未保存的修改。

点击文件列表顶部“新建”或按 Ctrl+N 创建未命名文档，编辑锁定默认关闭，可直接输入。锁定状态按标签页单独保留。首次按 Ctrl+S 选择保存位置，取消后保留当前文稿，后续保存继续使用所选路径。

“复制 Markdown”复制当前文件的完整原文，包含尚未保存的修改，保留原文中的标记、空格和换行。预览支持表格、任务列表、代码高亮和相对路径图片。文件使用 UTF-8 编码。

| 快捷键 | 操作 |
|---|---|
| Ctrl+N | 新建 Markdown 文档，默认允许编辑 |
| Ctrl+O | 打开文件，可多选 |
| Ctrl+W | 关闭当前标签 |
| 鼠标中键 | 关闭指向的标签 |
| Ctrl+Tab / Ctrl+Shift+Tab | 下一个 / 上一个标签 |
| Ctrl+Shift+L | 切换当前文件的编辑锁定 |
| Ctrl+Shift+C | 复制完整 Markdown |
| Ctrl+S | 保存当前文件 |

保存使用同目录临时文件写入、同步和替换。保存前检查磁盘版本，遇到外部改动时提供重新载入、覆盖保存和取消。

## 阅读工具

文档顶部的“大纲”可展开右侧章节导航，支持折叠子章节、点击跳转和当前章节高亮。重复标题会生成独立锚点。大纲默认收起。

分栏模式默认开启原文与预览的双向同步滚动，按 Markdown 正文块对应位置定位。点击“同步滚动”可关闭，单独阅读两侧内容。

点击“搜索预览”或按 Ctrl+Shift+F 打开预览搜索。支持中文、跨行内加粗的连续文本、区分大小写、匹配数量和循环跳转。Enter / F3 跳到下一个，Shift+Enter / Shift+F3 跳到上一个，Esc 关闭。焦点在预览区时 Ctrl+F 也可打开，原文编辑区保留 CodeMirror 自带搜索。

点击预览中的图片可放大查看，支持滚轮缩放、拖动平移、适应窗口和原始大小。图片获得焦点后可按 Enter / 空格打开，查看时按 + / - 缩放、0 适应、1 恢复原图、Esc 关闭。

允许编辑时，在原文中粘贴截图或 PNG、JPEG、GIF 图片，会保存到文档旁的 `<文档名>.assets` 目录，并在光标位置插入相对路径链接。未保存文档会先提示选择保存位置，取消后保留文稿。插入图片后按 Ctrl+S 保存 Markdown。

每个围栏或缩进代码块右上角提供“复制”按钮，复制代码正文并保留缩进与换行。

## 开发与构建

需要 Windows x64、Go 1.25+、Node.js 22.12+ 和 Wails CLI `v3.0.0-beta.19`。Go 模块指定 `go1.25.13` 工具链，Go 可按需自动下载。

```powershell
git clone https://github.com/fengfengzhidao/markdown-preview.git
cd markdown-preview
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0-beta.19
wails3 build
```

构建任务安装前端依赖、生成 Go 绑定、编译前端并输出 `bin/MarkdownLite.exe`。Windows 需要 WebView2 Runtime。

开发模式使用以下命令。

```powershell
wails3 task dependencies
wails3 dev -config ./build/config.yml -port 9256
```

前端构建完成后可执行文件存储与图片路径的回归检查。

```powershell
go test ./...
go vet ./...
```
